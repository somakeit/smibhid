BH1750 Light Sensor Management

Configure your BH1750 digital ambient light sensor for accurate lux measurements and space occupancy detection. The sensor continuously monitors light levels and can help determine whether your space is open or closed based on configured thresholds.

🎯 Resolution: 1 lux (high-res mode), 0.5 lux (high-res mode 2)
📊 Range: 1-65535 lux
🌟

Light Threshold Configuration

Set the light level threshold for space occupancy detection. Light levels above this threshold indicate the space is "open".

💡
Configuration Tips:
  • Monitor typical light levels when space is occupied
  • Set threshold below typical occupied light levels
  • Consider ambient light from windows/skylights
  • Set to 0 or "none" to disable light-based detection
